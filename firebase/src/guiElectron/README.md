# WebRTC USB/IP Electron Bridge

This package contains the complete, working replacement for the SDL-based GUI, integrating a headless C++ WebRTC/USBIP engine with a modern Electron GUI via an IPC standard input/output bridge.

## Project Structure
```text
.
├── CMakeLists.txt            # Updated CMake configuration without SDL2
├── gui/
│   ├── main.cpp             # Headless C++ main entry point reading stdin / emitting stdout
│   ├── gui.h                # Headless GUI interface stub
│   └── logsync.h            # Headless logging sink
└── electron/
    ├── package.json         # Node.js / Electron package dependencies
    ├── main.js              # Electron main process spawning guiElectron
    ├── preload.js           # Secure contextBridge API for the renderer
    ├── index.html           # Dark-themed GUI layout matching original SDL features
    └── renderer.js          # Interactive button listeners and device list rendering
```

## Quick Start Instructions

### 1. Build the C++ Backend
In your project root (where `CMakeLists.txt` is located):
```bash
cmake -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --config Release
```
This generates `build/Release/guiElectron.exe` (or `build/guiElectron` on Linux).

### 2. Run the Electron Frontend
Navigate to the `electron/` directory:
```bash
cd electron
npm install
npm start
```

### 3. End-to-End Testing
- **Host (Machine A):** Click **Host (Local USB)**. Your local devices will populate the left pane, and a Room ID will be displayed.
- **Client (Machine B):** Enter the Room ID generated by Machine A, then click **Connect (Remote USB)**.
- Once the **DataChannel: Open** badge turns green, remote devices will appear. Select a device and click **Attach Selected**.
- To finish, click **Detach All** to disconnect the virtual USB device and reset the tunnel.
